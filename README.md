# NRf24-transiver-reciver
testing komunikasi menggunakan modul nrf24 + arduino nano
component list
Komponen yang Digunakan

📤 Pemancar (Transmitter - Tx)

Microcontroller: Arduino Nano

Modul Wireless: NRF24L01

Input: Joystick Module / Push Button

Power: Baterai Li-Ion / LiPo + Module Charging (TP4056)

📥 Penerima (Receiver - Rx)

Microcontroller: Arduino Nano

Modul Wireless: NRF24L01

Output: Servo Motor / LED 

Power: Baterai
